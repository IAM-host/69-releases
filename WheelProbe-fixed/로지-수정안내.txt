TXT에는 전체 코드만 들어 있습니다. 기존 E05의 전체 내용을 교체합니다.

삭제한 내용
- 제공된 로지D1·D2 APK에 없는 FakeGpsDetector와 FusedLocationApi 이름을 찾던 구간.
- 위 조회 실패 뒤에는 실행되지 않던 모의 위치 설정 조회 구간.
- 다른 코드에서 사용하지 않는 LogiFakeGpsFalseHooker와 LogiMockLocationAppSettingHooker 두 개.

유지한 내용
- Android Location의 위도·경도 좌표 훅 및 각각의 독립 설치·오류 기록.
- D1(com.logisoft.Logi4)·D2(com.logisoft.Logi5)의 앱 구분과 전면 실행 대상.
- 콜 데이터, SET 조건, 일반/탁송 분류, 원래 수락 처리, 성공 확인 후 감지 OFF.
- 직전 콜마너1·2 수정과 패키지·조건·GPS 전달 설정.

이번 삭제는 EUNORA 안의 잘못된 조회 코드를 정리한 것입니다. 로지 APK 자체를 수정한 작업은 아닙니다.
로그의 coordinates registered=2/2는 위도·경도 훅 등록을 뜻하며, 실제 좌표 적용·서버 송신까지 확인했다는 의미는 아닙니다.
잘못된 조회와 legacy target unavailable 로그를 내던 구간은 삭제했습니다.

이전 연결 수정본을 이미 적용한 경우 E05만 교체해서 빌드·설치하면 됩니다.
이전 로지D2·콜마너2 연결 수정본을 아직 적용하지 않았다면 같은 폴더의 ModuleMain.kt.txt, E04.kt.txt, ConditionProvider.kt.txt, AndroidManifest.xml.txt, scope.list.txt도 적용 안내에 맞춰 반영합니다. 새 런타임 Kotlin 파일은 필요하지 않습니다.

설치 후 LSPosed에서 사용할 로지D1·D2 적용 범위를 확인하고, 실행 중인 로지 앱을 강제 종료한 뒤 재실행합니다.

검증
- 실제 Android assembleDebug 성공.
- 실제 E05의 좌표 훅 설치·D1/D2 라우팅·설정 연결 54개 검사 통과.
- TXT는 빌드한 E05와 바이트가 같습니다.
- 실제 휴대폰의 좌표 적용·전송과 콜 수락은 아직 검증하지 않았습니다.
