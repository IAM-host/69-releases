# EUNORA 로지 D1 21.55 대응 · 2026-11-25

현재 전달본 E05를 로지 D1(com.logisoft.Logi4, 21.55, versionCode632)의 확인된 구조에 맞춘 수정본입니다.

## 적용

1. Android Studio에서 기존 E05.kt를 별도로 백업하세요.
2. 이 폴더의 E05.kt 전체를 프로젝트의 app/src/main/java/com/example/wheelprobe/E05.kt에 교체하세요.
3. E05.txt는 동일한 전체 코드를 메모장에서 열기 위한 파일입니다. TXT 자체를 프로젝트에 추가하지 마세요.
4. 앱을 다시 빌드·설치하고, 로지를 강제 종료한 뒤 재실행하여 모듈이 새 코드로 로드되게 하세요.

교체 파일은 E05 하나입니다. ModuleMain, 조건·회원·업데이트·GPS 설정과 다른 앱의 코드 파일은 이 묶음에 포함하지 않습니다. 이전 SET 6개 화면 작업과 이번 로지 수정은 합치지 않았습니다.

## 수정 범위

- 21.55의 실제 앱 수락 경로, 응답 데이터·작업 스레드·확인 창 연결을 사용합니다.
- 서버 성공 응답과 요청 ID 확인, 중복 요청 방지, 감지 세션 변경 시 확인을 유지합니다.
- 기존 21.53 연결과 새 21.55 연결을 구분합니다. 새 21.55 경로는 확인된 D1 패키지와 버전 코드에 한정합니다.
- 기존 Java 루팅·후킹 보고서 구조와 새 21.55 결과 구조를 구분합니다.

설치 앱 목록 조회·EUNORA 숨김은 변경하지 않았습니다. 네이티브 TMap 초기화의 별도 루팅 검사, 통신 인증·서버 판정도 변경하지 않았습니다. 따라서 모든 보안 검사가 처리된 수정본이라는 의미는 아닙니다.
