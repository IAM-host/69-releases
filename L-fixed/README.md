# L 내부 정리본 — 2026-11-17

기존 L.exe의 화면 배치와 버튼 스타일을 유지하면서 내부 코드를 분리한 소스입니다. 기존의 로그·세션·후보군·APK 추출/비교·구조 분석·훅 지도 탭을 유지했습니다.

**main.py 하나만 교체하는 버전이 아닙니다. `main.py`와 `l_app` 폴더를 함께 사용해야 합니다.** 전체 ZIP을 새 폴더에 풀어 실행하세요. 기존 폴더의 사용자 데이터는 ZIP에 들어 있지 않습니다.

## 실행

Windows에 Python 3.10 이상이 설치돼 있어야 합니다.

1. ZIP 전체를 풀고 `run_L.bat`를 실행합니다.
2. 첫 실행에는 이 폴더의 `.venv`에 PySide6를 설치합니다. 초기 설치는 인터넷 연결이 필요합니다.
3. USB 기능을 사용하려면 Android SDK platform-tools의 `adb.exe`가 필요합니다. 기존 Android Studio 기본 설치 경로와 PATH에서 찾습니다.
4. JADX XREF는 별도로 설치한 JDK와 JADX가 필요합니다. REA·Codex·AI 모델은 이번 버전에 추가하지 않았습니다.

Python에서 직접 실행할 때는 프로젝트 폴더에서 다음과 같이 실행합니다.

```cmd
python -m pip install -r requirements.txt
python main.py
```

## L.exe 만들기

`build_L.bat`를 실행하면 필요한 패키지를 이 폴더의 `.venv`에 설치하고 `dist\L.exe`를 생성합니다. 이 스크립트는 **Windows PC에서** 실행해야 합니다. 현재 전달물은 소스이며, Windows에서 빌드한 새 EXE를 포함하지 않습니다.

새 EXE를 기존 L.exe가 있던 폴더에서 사용하면 기존 `sessions`, `apks`, `hooks.json`, `eunora_hooks.json`을 같은 위치에서 읽습니다. 소스로 실행하면 `main.py` 옆에 데이터를 저장합니다. 필요하면 `L_APP_DATA_DIR` 환경변수로 데이터 폴더를 명시할 수 있습니다.

## 이번 변경

- 화면 코드, 앱 정보, APK/DEX 분석, ADB 실행, 저장·치환, 백그라운드 작업을 별도 모듈로 분리했습니다.
- 콜마너1·2, 로지D1·D2를 구분해 총 7개 패키지를 선택할 수 있습니다. 기존 세션·APK 기록의 앱 키는 유지했습니다.
- APK 추출·비교·JADX·구조 분석·지도 대조를 작업 스레드로 옮겼습니다. 긴 분석 중에도 GUI 이벤트와 로그 수신이 유지됩니다.
- 창을 닫으면 진행 중인 작업에 취소를 요청하고 해당 작업이 만든 하위 프로세스를 정리합니다.
- 로그가 여러 번에 나뉘어 들어와도 한글과 줄이 깨지지 않도록 모읍니다.
- base APK 추출 실패 시 split APK를 base로 바꾸지 않습니다. 불완전한 추출과 정적 문자열 발견을 명확히 표시합니다.
- JADX 캐시는 APK·도구·옵션·출력 목록을 확인합니다. 일부 함수만 복원된 결과는 부분 복원으로 표시합니다. 캐시의 파일 목록과 크기를 확인하는 것이며 수동으로 바꾼 동일 크기 코드의 의미까지 검증하는 기능은 아닙니다.
- 코드 치환은 정확한 Kotlin 문자열 값만 대상으로 하고 주석·부분 문자열·보간식은 유지합니다. 여러 후보가 있으면 임의로 하나를 고르지 않습니다.
- 대조 후 원본이나 APK가 바뀌면 복사본 생성을 중단합니다. 생성한 복사본을 다시 원본으로 선택해도 그 파일을 덮어쓰지 않습니다.
- 저장 실패 시 원본 파일·캡처 로그를 보존합니다. 잘못된 hooks.json을 사용자가 다시 저장할 때는 이전 내용을 별도 파일로 보관합니다.

## 분석 결과의 의미

APK 문자열 발견, DEX 참조 발견, 실제 훅 등록, 기기에서의 훅 실행은 서로 다른 단계입니다. 이번 버전의 정적 분석과 치환 후보는 실제 동작을 입증하지 않습니다. 생성된 Kotlin 복사본은 빌드·기기 확인이 필요한 결과입니다.

이번 작업은 내부 구조 정리입니다. REA 연결, AI 연결, EUNORA 전체 프로젝트를 이해하는 새 훅 자동 생성기까지 구현한 버전은 아닙니다. 훅 지도는 기존 ModuleMain 대조 기능을 유지하면서 치환 범위와 파일 보존을 보강했습니다.

## 구조

- `main.py`: 실행 진입점
- `l_app/ui.py`: 기존 화면과 결과 표시
- `l_app/jobs.py`, `processes.py`: 백그라운드 작업·취소·외부 도구 실행
- `l_app/adb.py`: 기기 명령과 APK 추출
- `l_app/analysis.py`: DEX/APK/JADX 분석
- `l_app/config.py`: 7개 앱 정보와 기본 규칙
- `l_app/logs.py`: 로그 필터·요약·수신 버퍼
- `l_app/state.py`, `paths.py`, `workflows.py`: 기록·경로·원본 보존과 대조/복사본 생성

## 검증

`run_tests.bat` 또는 `python -m pytest -q`로 검사합니다. GUI 검사는 화면을 표시하지 않는 Qt offscreen 모드입니다.

전달 전 Linux의 Python 3.12/PySide6 환경에서 89개 테스트와 12개 하위 검사가 통과했습니다. 원본의 실제 위젯 구성으로 만든 기준 자료와 탭·버튼·스타일·창 크기를 비교했습니다. 가짜 ADB 및 임시 파일로 추출 실패·치환·저장 오류를 검사하고, 실제 생성한 테스트 프로세스로 취소를 검사했습니다.

실제 Windows EXE 실행, 실제 휴대폰·콜 수신·서버 요청은 검증하지 않았습니다. 기존 APK 비교·로컬 분석 도구 기능을 위한 소스 리팩터링입니다.
