# EUNORA 보안 코드 수정본 — 2026-11-18

마지막으로 첨부한 WheelProbe.zip을 기준으로 **기존 E02~E06 다섯 파일의 보안 처리만 수정한 전체 코드**입니다. 각 파일에는 기존 콜·수락·GPS 코드가 포함되어 있으며, 그 부분은 원본 바이트를 보존했습니다.

## 적용 방법

1. 기존 프로젝트를 백업한 뒤 `EUNORA-security-update.zip`을 압축 해제합니다.
2. 압축 안의 `EUNORA-security-20261118/app` 폴더를 기존 WheelProbe 프로젝트의 `app`에 병합하여, 같은 경로의 **E02.kt, E03.kt, E04.kt, E05.kt, E06.kt만 교체**합니다.
3. Android Studio에서 빌드하여 새 APK를 설치합니다. LSPosed 모듈 적용 상태를 확인하고 대상 앱 프로세스를 완전히 종료한 뒤 다시 실행합니다.

메모장으로 복사하려면 `txt/E02.txt`~`txt/E06.txt`를 열어 각 기존 Kotlin 파일의 전체 내용을 교체하면 됩니다. TXT에는 설명이나 코드 블록 표시가 없으며 해당 `.kt`와 바이트 단위로 같습니다. TXT를 별도 Kotlin 소스 파일로 추가할 필요는 없습니다.

ModuleMain.kt, E01.kt, 조건·금액·거리 판정, UI, GPS, manifest, scope 파일은 교체하지 않습니다. L도 수정하지 않았습니다. 이 압축에는 APK가 포함되어 있지 않습니다.

## 변경한 처리

| 파일 | 변경 내용 |
|---|---|
| E02 / 카카오 | 확인된 루팅 상태와 후킹 보고서 결과를 처리합니다. 보고서는 새 객체로 만들고 파생 값을 다시 계산합니다. 미확인 API 항목과 원래 검사 오류는 보존합니다. 잘못 추정한 클래스의 등록을 제거하고 Sentry 설정의 ClassLoader 충돌을 수정했습니다. |
| E03 / T맵 | 기존 루팅 훅의 대상·반환형·명령 인수를 확인합니다. 정확한 `which su` 명령만 처리하며 환경변수·작업 폴더·다른 인수를 보존합니다. |
| E04 / 콜마너 | 확인된 Crashlytics 루팅 진단 함수와 정확히 일치하는 루팅 파일 경로를 처리합니다. |
| E05 / 로지 D1·D2 | 확인된 루팅·Xposed 보고서 결과를 처리합니다. 미확인 항목, Frida·디버거 항목과 다른 스택 증거는 보존합니다. 동시 설치 및 로그 실패로 훅 처리 정보가 손실되던 문제를 수정했습니다. |
| E06 / 아이드라이브 | 확인된 Crashlytics 루팅 진단 함수와 정확히 일치하는 루팅 파일 경로를 처리합니다. |

실제 결과 변경, 설치 완료, 대상 미지원은 로그에서 구분합니다. 대상이 없거나 구조가 바뀐 경우 성공했다고 표시하지 않습니다. 별도 Debug/Release 실행 조건이나 새 Android 소스 파일은 추가하지 않았습니다.

## 확인 결과

- 수정된 전체 프로젝트의 `compileDebugKotlin`과 `compileReleaseKotlin` 모두 성공했습니다. APK 조립·서명 검사는 수행하지 않았습니다.
- 실제 수정 보안 소스를 추출하고 libxposed API100을 사용한 JVM 검증 **830개 assertion**을 통과했습니다: 카카오 99, 로지 564, 나머지 167.
- 원본 파일 69개와 콜·수락·GPS 등 보호 선언 106개가 바이트 단위로 동일합니다. ModuleMain도 동일합니다.
- 컴파일 경고는 원본에도 있던 접근성 API 사용 중단 경고와 E02의 nullable 경고입니다. 클라우드 SDK 경로 관련 경고도 있었으며 컴파일은 성공했습니다.

자세한 해시와 검증 결과는 `VALIDATION.json`, 변경 비교는 `changes.diff`에 있습니다. diff는 검토용으로 줄바꿈을 LF로 정규화했으며, 실제 교체 파일과 TXT는 검증한 원본 바이트 그대로 보관했습니다.

## 확인하지 못한 범위

실기기에서 LSPosed 실행과 서비스 동작은 아직 확인하지 않았습니다. 콜마너·아이드라이브의 Crashlytics 진단 처리는 서비스 차단 판정 전체를 해결했다는 의미가 아닙니다. T맵 APK가 없어 기존 대상의 최신 버전 의미까지 검증하지 못했습니다. 네이티브·Flutter 검사, 서버 및 Play Integrity 판정은 이번 수정에 포함되지 않습니다.

카카오는 제공된 디컴파일 소스, 로지 D1·D2와 콜마너2·아이드라이브는 사용 가능한 APK의 DEX, 콜마너1은 제공된 디컴파일 소스와 대조했습니다. 지원하지 않는 버전·시그니처·결과나 원래 예외는 보존하도록 검증했습니다.
